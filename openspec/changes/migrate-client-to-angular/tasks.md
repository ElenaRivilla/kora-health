# Tasks

Cada sección es una fase de implementación y se delega a un subagente que arranca sin contexto. Antes de empezar cualquier sección hay que leer `CLAUDE.md`, `proposal.md` y `design.md` de este change (las decisiones 1–12 del design no se reabren) y comprobar que todas las casillas de la sección anterior están marcadas: una fase no se abre hasta que la anterior cierra. Las fases 0 y 1 del proposal (design, deltas de spec y este archivo) ya están hechas.

Reglas comunes a todas las secciones:

- Las rutas `src/...` son relativas a `kora-health-web/`; el resto, a la raíz del repositorio.
- Lo que la usuaria ha dejado fuera de este change (decisiones 10 y 12 del design) no genera tareas ni huecos: no se incluye Firebase; no se crean `authGuard` ni servicios de autenticación o sesión, ni siquiera como carpeta, archivo vacío o placeholder (llegarán con `add-auth`); no se implementan traducciones (textos en español en las plantillas); no se crea ningún pipe; no se instala Capacitor, no se crea el contrato de HealthKit y ningún código asume un entorno nativo.
- Las Open Questions del design tampoco son tareas: se aplican sus valores por defecto (sin librería de estado ni de componentes, sin animaciones, sin SSR). El runner de pruebas ya no es una pregunta abierta: es el que configure por defecto el CLI 22 (decisión 11), y la tarea 1.9 fija el comando no interactivo que reutilizan las demás secciones.
- Angular CLI no está instalado globalmente (la máquina tiene Node 24 y npm 11): todo comando `ng` se ejecuta con `npx` (`npx @angular/cli@22 ...` antes de que exista el proyecto; `npx ng ...` dentro de `kora-health-web/`). No se instala un CLI global.
- Una tarea de verificación solo se marca si el comando se ha ejecutado de verdad y ha dado el resultado indicado. Si algo impide ejecutarla (por ejemplo, la API no arranca), se para y se informa a la usuaria; no se marca.
- Durante las secciones 1 a 4 no se toca `kora-health-client/` (Flutter sigue intacto y ejecutable).
- No se hacen commits salvo donde una tarea lo indique expresamente.
