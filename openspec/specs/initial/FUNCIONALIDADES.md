# Funcionalidades

## Objetivo del proyecto

La aplicación tiene como objetivo centralizar toda la información relacionada con la salud, la nutrición y el entrenamiento del usuario en una única plataforma.

Se integrará con Apple HealthKit para obtener las métricas de salud disponibles en el dispositivo y permitirá registrar entrenamientos y alimentación mediante inteligencia artificial.

La aplicación estará compuesta por cinco módulos principales:

- Salud
- Nutrición
- Entrenamientos
- Progreso
- Perfil

---

# 1. Salud

El módulo de Salud será el encargado de sincronizar y visualizar las métricas procedentes de Apple HealthKit.

## Funcionalidades

- Sincronización con HealthKit
- Peso
- IMC
- Porcentaje de grasa corporal
- Masa muscular
- Frecuencia cardíaca
- Variabilidad cardíaca (HRV)
- Saturación de oxígeno
- Sueño
- Pasos diarios
- Distancia recorrida
- Calorías activas
- Calorías en reposo
- VO₂ Max
- Históricos
- Gráficas
- Evolución temporal

---

# 2. Nutrición

El módulo de Nutrición permitirá registrar toda la alimentación diaria del usuario.

## Diario nutricional

El usuario podrá registrar:

- Desayuno
- Almuerzo
- Cena
- Tentempié

Cada comida podrá contener uno o varios alimentos.

## Registro de alimentos

La aplicación permitirá:

- Añadir alimentos manualmente.
- Registrar comidas mediante fotografía.
- Detectar alimentos utilizando IA.
- Calcular automáticamente:
    - calorías
    - proteínas
    - carbohidratos
    - grasas
    - fibra
    - azúcar
    - sodio

## Objetivos diarios

El usuario podrá configurar:

- Calorías
- Proteínas
- Carbohidratos
- Grasas
- Fibra
- Azúcar
- Sodio

## Puntuación nutricional

La aplicación calculará una puntuación nutricional diaria basada en la calidad de la alimentación.

La IA podrá explicar el motivo de dicha puntuación y ofrecer recomendaciones.

## Agua

Registro de consumo diario de agua.

Características:

- Objetivo diario
- Registro rápido
- Historial
- Estadísticas

## Recetas

El usuario podrá guardar recetas propias para reutilizarlas posteriormente.

# Inteligencia Artificial

La IA estará integrada de forma transversal en toda la aplicación.

Casos de uso:

- Reconocimiento de alimentos mediante imágenes.
- Estimación de cantidades.
- Cálculo nutricional.
- Explicación de la puntuación nutricional.
- Recomendaciones alimentarias.
- Recomendaciones deportivas.
- Análisis de tendencias.
- Resúmenes personalizados.
- Respuesta a preguntas del usuario utilizando el contexto completo de sus datos.
